C57BL/6J小鼠耳鸣造模与GPIAS、PPI、ABR检测详细实验Protocol

版本：2026-10-26 · 可用于实验室先导方案、SOP草案和伦理申请材料的结构化底稿
范围：水杨酸钠（急性、相对可逆）及噪声（声损伤后持续性）两种模型；清醒GPIAS/PPI；麻醉ABR。
重要限制：本文件区分了文献原始条件、跨论文组合的建议参数和需先导验证的实验室设置。不能把GPIAS异常或ABR阈移单独当作“确诊耳鸣”。麻醉、注射、噪声致损伤条件必须经机构动物伦理与兽医审批。

0. 方法学来源与复现原则

  • [R1] Yu et al., 2016：水杨酸钠300 mg/kg，0.9% NaCl稀释，腹腔注射，连续3天；末次给药后约2 h检测。GPIAS使用50 ms声音间隙、Gap结束后15 ms出现20 ms/115 dB SPL惊跳声，背景声可设置60–80 dB SPL（细节见后）。原文仅用2–4月龄雄性小鼠，并非已验证所有年龄和性别。
  • [R2] Rybalko et al., 2023：61只2–3月龄C57BL/6J（雄27、雌34）；10 kHz中心频率、1/3倍频程窄带噪声、116 dB SPL、1 h，氯胺酮35 mg/kg＋赛拉嗪6 mg/kg麻醉并于37℃加温垫暴露；第2周通过GPIAS分类。研究的GPIAS时序、惊跳声强度与[R1]并不相同。
  • [R3] Cui et al., 2018：2月龄雄性C57BL/6J，用50 mg/mL生理盐水水杨酸钠工作液，200 mg/kg/天×14天。由此获得50 mg/mL配液浓度的独立文献支持；把其与[R1]的300 mg/kg×3天组合用于先导实验时，须明确这是跨论文组合，不是[R1]原文宣称的配置方法。
  • [R4] Akil et al., 2016：鼠ABR标准化麻醉、电极布置、Click和Tone burst刺激以及阈值判读。
  • [R5] Fabrizio-Stover et al., 2022：CBA/CaJ模型中，GPIAS与操作性声音判断结果可能不一致，116 dB噪声暴露可使部分动物因听力下降退出行为学评估。其113 dB方案不可不经验证直接等同于C57BL/6J模型。
  • [R6] 滕琪等, 2025：以6周龄雄性C57BL/6J对照鼠重复测试的自然波动设阈值，2倍标准差为0.16（比例单位，即16个百分点）；存在假阳性，阈值需由本实验室自身对照数据校准。

1.2 分组和实验单位

建议设4组：①生理盐水腹腔注射对照；②水杨酸钠腹腔注射；③假噪声暴露（含相同麻醉、搬运、声场放置操作）；④窄带噪声暴露。不同模型应有各自的操作匹配对照，不能仅共享一个未处理空白组。

建议先以每组4–6只做工艺先导与方差估计，这不是正式效应检验样本量；正式样本量基于主要终点、预期差异、方差、目标功效及不可评价比例计算。预先指定个体小鼠为实验单位。尽量完成基线后分层随机与盲法数据判读。

二、Protocol A：水杨酸钠诱导耳鸣样状态

2.1 材料与耗材

  • 水杨酸钠 Sodium salicylate（例如Sigma S3007，核对盐形式和纯度）；无菌0.9% NaCl；洁净配液容器、分析天平、经验证的无菌过滤工具。
  • 注射用1 mL小体积注射器、机构认可的皮下注射/腹腔注射针头（常用27–30 G，具体由动物中心规范确定）、注射记录表和电子小鼠秤。
  • 配液前核对试剂的批号、纯度、有效期；水杨酸（salicylic acid）不能按同质量直接替代水杨酸钠。

2.2 工作液配制：50 mg/mL（示例配制10 mL）

  1. 依据当次动物数量估算用量，不应为节约劳动一次配制过量。
  2. 核对药品为水杨酸钠。称取500 mg，记录实际质量。
  3. 加入约8 mL无菌0.9% NaCl，轻摇或温和搅拌至全部溶解。
  4. 再以无菌0.9% NaCl定容至10.0 mL，最终浓度50 mg/mL（5% w/v）。
  5. 观察澄清度、颗粒与沉淀；核对pH和注射用无菌要求。若采用滤膜过滤，滤膜相容性和流程须按机构药剂/兽医规程验证。
  6. 标注名称、浓度、溶剂、配制人、日期、批号；先导阶段优先现配现用，不自行假定稳定储存期限。

来源说明：50 mg/mL由[R3]中C57BL/6J长期给药研究直接支持；本方案把它用作便于计算的配液浓度，并采用[R1]的300 mg/kg×3天剂量。组合前需审查注射体积和制剂耐受性。

2.3 给药剂量、体积与示例

推荐先导目标剂量：水杨酸钠300 mg/kg，腹腔注射（i.p.），每天1次，连续3天；同组每天尽量固定时间，例如09:00。盐水对照采用等体积0.9% NaCl。[R1]

2.4 腹腔注射操作顺序

  1. 检查小鼠编号、组别、当前健康状态，称重并记录。对精神萎靡、呼吸异常、持续体重下降或其他满足暂停标准的动物先进行兽医评估。
  2. 按公式计算注射体积，独立核对单位。抽取对应体积的制剂，检查气泡、沉淀和标签。
  3. 由经培训的操作者按所在动物中心批准的i.p.注射规范保定，在规范指定的腹部区域进针，避开膀胱、肠道及主要血管；具体进针角度与深度须以面对面动物操作培训为准。
  4. 缓慢注射；异常阻力、出血或药液外漏时停止并按不良事件流程记录，不自行反复盲目进针。
  5. 返回饲养笼，记录精确注射时间、体积、操作者、动物状态与异常情况，按预设时间开展观察。
  6. 给药后监测步态、反应、呼吸、饮食、体重与活动；预设停止给药及人道终点，包括持续不能正常摄食饮水、明显呼吸异常或严重活动受限等。

2.6 水杨酸钠模型判断

观察：①基线ASR/GPIAS有效；②给药后特定频段GPIAS抑制下降；③PPI和原始惊跳幅度未出现足以解释这一结果的严重变化；④ABR排查显著听觉混杂；⑤停药后有恢复趋势。单次GPIAS下降不能作为耳鸣确诊，也不等于药物只影响中枢而不影响耳蜗。

三、Protocol B：噪声诱导耳鸣样状态

3.1 文献方案与适用范围

[R2]使用2–3月龄、雌雄均纳入的C57BL/6J，共61只；在麻醉下使用中心频率10 kHz、1/3倍频程的窄带噪声，116 dB SPL × 60 min。注意这是会导致听力损伤的声暴露条件，不是“最佳耳鸣诱导强度”的通用结论。原研究GPIAS评估的主要窗口为暴露后2周。

3.2 设备清单与声学准备

配备：隔声/消声箱、高频扬声器、噪声源（数字白噪声＋带通滤波）、功率放大器、计算机控制与记录系统、可溯源校准的1/4英寸测量麦克风和声级计、温控加热平台、麻醉监护设备。

每次实验前按顺序完成：

  1. 固定扬声器、动物头位和保定系统，避免更改距离、角度和材料产生不可控反射声。
  2. 生成宽带噪声，通过带通滤波形成10 kHz中心、1/3 octave频带；保存输出信号、滤波器阶数/带宽与软件版本。
  3. 将测量麦克风置于小鼠头部真实所在位置，而不是放在扬声器出口处。
  4. 逐步调整放大器增益，校准为目标116 dB SPL，检查声压频谱和持续性；分别测量头部位置的多个点，记录均匀度。
  5. 建议把头部工作区域偏差控制在±2 dB内作为本实验室建议QC目标，而非冒充原文固定要求。
  6. 开始前确认操作人员职业听力保护、隔声完整性，以及实验箱内外安全性。

原创技术示意图。

3.3 动物麻醉与放置

[R2]报告氯胺酮35 mg/kg＋赛拉嗪6 mg/kg麻醉、加热垫37℃。该数值只能视为原论文使用条件，不能替代机构麻醉方案。60 min噪声暴露需制定麻醉深度与呼吸监护、保温、可能的补充麻醉、复苏和人道终点方案，经兽医审批。

  1. 核对编号、性别、体重、分组，完成当日健康评估。
  2. 确认麻醉设备、保温平台、复苏器材和噪声发生器的状态。
  3. 按批准方案实施麻醉，检查适当麻醉深度、呼吸、体温和姿势。
  4. 将小鼠置于经校准的头位，保证呼吸道通畅，身体未受不当压迫；记录开始时间。
  5. 假暴露组接受相同麻醉、保温、搬运及声箱内停留时间，但不给予致损伤噪声。

3.4 噪声暴露与复苏

  1. 核对噪声模式10 kHz中心、1/3 octave、116 dB SPL、计划60 min。
  2. 按设备SOP启动声源，记录真实起止时间与中断。
  3. 暴露期间在避免对人员产生高噪声危害的条件下观察呼吸、保温和麻醉状态；若出现异常则按预定终止标准执行。
  4. 完成60 min后关闭声源，记录实际累计暴露时间；异常暴露不应随意追加补足。
  5. 转至麻醉复苏区并持续监护，直至符合恢复标准后回笼。
  6. 次日按方案观察体重、一般状态并进行早期ABR。

3.5 是否改为113 dB？

[R5]中CBA/CaJ小鼠的116 dB处理导致更多听力严重受损而无法参加行为测试的个体；作者后来采用更温和的113 dB条件。但[R5]所用鼠种背景、暴露频率及方法与[R2]不同，113 dB不可直接当作经验证的C57BL/6J替代条件。建议先导考察听力损伤、可检测GPIAS比例、动物福利和持续表型，再根据伦理审批确定最终暴露条件。

四、Protocol C：GPIAS（清醒状态声惊跳间隙前抑制）

4.1 原理与限制

连续背景声中插入一个短暂Gap；若小鼠听到Gap，其随后的声惊跳反射幅度通常降低。GPIAS下降可能与耳鸣相关，但亦可能受到听阈变化、注意、感觉运动门控、背景声掩蔽、原始惊跳幅度或惊跳习惯化影响，因此必须联合PPI、ABR和原始试次分析。[R5]

原创技术示意图。

4.2 仪器配置

SR-Lab（San Diego Instruments）、Med Associates或其他能精确控制高频声背景、静音Gap、短声惊跳刺激并同步采集力/位移/电压输出的系统。应有隔声箱、可校准麦克风、惊跳平台和原始数据保存能力。

4.3 区分两个独立、真实发表的GPIAS范式

范式A：优先用于复现水杨酸钠研究[R1]，而不是声称适用于所有模型。

项目 [R1]主要参数
背景声 1 kHz带宽NBN或BBN；中心频率8、10、12、16、20、24、32 kHz等
背景强度 60、65、70、75、80 dB SPL可选；频率筛查使用80 dB
Gap时长 50 ms，边缘约0.1 ms
Gap结束至惊跳开始 15 ms
惊跳声 115 dB SPL白噪声，20 ms
试次间隔 8–12 s，随机
试次结构 起始20次惊跳＋每频率20次（Gap/No-gap各10次）＋末尾5次惊跳
动物状态 清醒

范式B：优先用于复现噪声研究[R2]。

这两套参数不能直接混为一套“原文复现协议”。为了不同模型之间直接比较，同一实验室可经先导优化后采用统一检测范式，但须在论文中写作“本实验室修改后范式”，明确修改之处。

4.4 设备校准与日常QC

  1. 检查设备开机、声源、放大器、声箱密封与采样通道。
  2. 将麦克风放在限制筒内预计头位，逐项实测背景声和惊跳声声压级。
  3. 频谱确认：特别是16、24、32 kHz等高频段，不能仅凭厂家标称扬声器频响。
  4. Gap期间声能应可靠降低至箱内本底附近，并避免开/关声产生可见的瞬态伪迹或可听的额外点击声。
  5. 检查惊跳平台空载本底、力传感器工作范围、采样率及有无饱和。
  6. 保存当天声学校准文件、设备软件版本、操作者和环境信息。

4.5 动物适应与基线测量

适应第1天：将清醒小鼠置入尺寸合适的通气限制筒，隔声箱内适应约5–10 min；进行少量惊跳试次，确认小鼠能产生可测量反射、不持续挣扎、平台不饱和。结束后记录总体反应。

适应第2天：重复适应，并加入部分Gap和No-gap试次，确认有稳定的基础间隙抑制。不要单凭一次无Gap反应过低便永久排除动物；先排除设备及保定问题，按照事先定义的有效性标准处理。

正式基线：在已预设频率和固定方案下采集原始逐试次反应；必要时不同日期重复测量以获得个体和假处理对照的自然波动。

4.6 正式测量逐步操作（以范式A为例）

阶段一：起始基础惊跳反射（ASR）

  1. 确认小鼠清醒且状态允许行为测试，输入ID与组别掩码。
  2. 入限制筒，静置约5 min，使其熟悉箱内环境。
  3. 给出20次20 ms、115 dB SPL白噪声惊跳刺激；相邻间隔8–12 s随机。
  4. 记录每次反应，检查是否出现机械伪迹、极低反应或平台饱和。

阶段二：Gap/No-gap试次

  1. 按预定频率播放连续背景噪声。例如16 kHz中心、80 dB SPL。频率筛查可使用8、10、12、16、20、24、32 kHz和BBN；如果实验资源受限，须在先导中预先选择核心频率，不能事后挑显著者。
  2. No-gap试次：背景持续不间断，按预设时序给予20 ms/115 dB SPL惊跳声；记录刺激后的反应幅度。
  3. Gap试次：惊跳前插入50 ms声音间隙（声学边缘约0.1 ms）；间隙结束15 ms后给予同样惊跳声；记录反应。
  4. 每个频率做10次Gap及10次No-gap，以伪随机序列交替，避免先集中全部No-gap再全部Gap。
  5. 不同背景频率的出现顺序跨动物平衡或预先随机，防止习惯化与频率顺序混杂。
  6. 在不同频率测试间维持一致的背景切换方式，记录是否产生声学瞬态。

阶段三：结束前ASR复测

  1. 完成所有频率后给予5次纯惊跳刺激。
  2. 对比起始与结束时原始ASR，判断是否出现明显习惯化或反射能力衰减。
  3. 退出小鼠，观察状况并返回笼内。

4.7 原始惊跳反射数据提取

  1. 每个试次保存原始模拟/数字波形与刺激事件时间戳。
  2. 将惊跳开始后100 ms定义为初始候选分析窗口（也可采用经设备验证的另一固定窗口）。
  3. 同一方案统一采用峰—峰值、峰值或RMS中的一种预先声明指标，不随意换算混用。
  4. 记录刺激前基线；按预定义标准剔除移动伪迹、机器振动、失真或饱和试次。
  5. 按动物、检测时间、频率、Gap类型计算平均ASR幅度与试次间变异。
  6. 保存剔除前后数据和剔除原因，统计人员在盲法状态完成质控。

4.8 GPIAS计算

$$\mathrm{GPIAS}(%)=\left(1-\frac{A_{\mathrm{Gap}}}{A_{\mathrm{NoGap}}}\right)\times100%$$

举例：造模前No-gap=2.0、Gap=1.0，GPIAS=50%；造模后No-gap=2.0、Gap=1.8，GPIAS=10%。这表示Gap抑制减弱，并不等于“耳鸣严重度增加40%”。

4.9 常规PPI作为辅助控制

PPI以真正的前置声音取代Gap，用于检查可听性和感觉运动门控。参考[R1]：75 dB SPL宽带前置声，或60–80 dB SPL的指定频率NBN；前置刺激50 ms；结束后70 ms给予20 ms/115 dB SPL惊跳声。原文PPI实验在安静背景中进行，区别于GPIAS的连续背景载波。

$$\mathrm{PPI}(%)=\left(1-\frac{A_{\mathrm{Prepulse}}}{A_{\mathrm{PulseOnly}}}\right)\times100%$$

若GPIAS和PPI同时大幅下降，应首先评估听力、感觉运动门控和总体ASR改变，不能直接认定耳鸣。

五、Protocol D：ABR（听觉脑干反应）

5.1 功能与仪器

ABR评估听觉传入通路的声诱发复合电位，主要输出频率特异性听阈、阈移、波I幅度/潜伏期及较晚波形改变。ABR阈值升高是听力变化证据，不能独立诊断耳鸣。

仪器可使用TDT RZ6/BioSig、Smart-EP或等效声学/电生理平台；需具备高频声学输出、可校准麦克风、3根皮下针电极、生物电放大器、隔声箱和恒温设备。[R2][R4]

5.2 麻醉与准备

[R1]使用氯胺酮80 mg/kg＋赛拉嗪12 mg/kg；[R4]提供的另一示例为氯胺酮100 mg/kg＋赛拉嗪10 mg/kg。不同机构用药浓度、品系、时长和生理状态差异明显，应由兽医制定和批准麻醉监护与复苏方案，不应将两者混合。

  1. 核对当日动物编号、体重、健康状态及耳道是否有明显堵塞。
  2. 按兽医批准方案麻醉；评估麻醉深度、呼吸、体温，提供眼部保护。
  3. 将小鼠安置在约37℃恒温平台；固定头位，保持呼吸道通畅。
  4. 将声源置于经校准的位置：闭场刺激可配合耳塞/耦合器测试左右耳；自由声场一般不等于单耳独立听阈。
  5. 检查声学系统当前校准文件，准备开始插入电极。

5.5 实际采集步骤

第一步：初始高声强检查

  1. 启动声学和采集系统，录入动物ID及处理组编码。
  2. 检查电极阻抗、温控系统和刺激校准。
  3. 从预设较高声强给予Click刺激，叠加500–1000次获得波形。
  4. 如未得到清晰诱发波形，先检查麻醉/体温、导线、电极阻抗、耳道/声学耦合，而不是立即提高到超出批准范围的声强。

第二步：Click ABR阈值搜索

  1. 保存起始声强原始波形；确认重复可见的I–V波或预定阈值判读目标波形。
  2. 按5 dB逐级降低声强，每一级使用相同采样、滤波和平均次数。
  3. 接近阈值时至少独立重复一遍；最好由两位盲法判读者独立审查。
  4. 最低仍可可靠识别的声强记为操作性ABR阈值；低于设备最低可测范围或高于输出上限时必须报告为截尾值，不填写虚假的精确阈值。

第三步：Tone burst听力图

  1. 固定每个频率的Tone burst包络、速率、平均次数与记录窗口。
  2. 依次测试8、16、24、32 kHz（或论文复现频率2、4、8、16、32 kHz）；不同动物频率顺序尽量平衡或预先固定。
  3. 每一频点由较高声强逐步降低，按相同步长查找阈值；接近阈值重复确认。
  4. 分别保存每个频点、每一级声强、每次重复的原始波形与最终判读记录。
  5. 需要比较左右耳时，逐侧重复，并确认刺激仅进入待测耳的技术前提。

第四步：波I及较晚波指标

在固定Click或Tone burst的相同超阈级别（最好使用相同的感觉级别或预先定义声压级方案）读取波I幅度、潜伏期及后续波形。必须明确幅度的正峰—负谷方向、分析窗口与参考点。不要把波IV/I比值解释为MGB特异性功能指标。

第五步：结束与复苏

保存记录与声学校准文件 → 移除电极并检查出血 → 按动物机构SOP监护麻醉复苏、体温和呼吸 → 记录恢复情况 → 达标后回笼。

5.6 数据计算与解释

$$\Delta\mathrm{ABR}{f,t}=\mathrm{Threshold}{f,t}-\mathrm{Threshold}_{f,baseline}$$

其中$f$为测试频点、$t$为造模后时间。阈值变化可反映暂时性或持续性听力损失，但与耳鸣样行为之间不应划等号。尤其在噪声造模后，要核实75/80 dB背景噪声处于动物可听范围，并在分析中考虑听阈对GPIAS的影响。

六、行为学成模标准与统计分析

6.1 推荐的预先定义标准

  1. 数据有效性：基线ASR可测且未饱和；GPIAS存在可评价基础抑制；Gap声学无额外瞬态；缺失试次比例处于预设范围。
  2. 对照波动：同批次假处理动物至少两个时间点的GPIAS测量差分分布，用于建立频率特异性或预设主频率的判定边界。
  3. 行为变化：造模后GPIAS下降，且变化幅度超过对照自然波动，并按预先指定频点报告。
  4. 排除混杂：核查PPI、原始ASR以及ABR；明显听力损失、反应丧失、设备伪迹时标记“不可评价”，不能当作耳鸣阴性或阳性。
  5. 持续性：噪声模型建议D14主要分类、D28重复确认；急性水杨酸钠模型在预定药效窗口判读并追踪恢复。

2025年[R6]研究的2SD=0.16只可作例子，不直接作为所有设备与性别/周龄的通用阈值。小鼠可能出现假阳性。

6.3 统计学与报告

  • 连续变量优先采用包含组别、时间、背景频率、性别及小鼠随机效应的纵向模型（或与设计一致的重复测量分析）；注意频点多重比较校正。
  • 报告效应量、置信区间和原始轨迹，不只报告P值；用个体数据展示异质性。
  • 如按“成模阳性”做后续干预，报告总暴露数、筛选成功数、未成功数和不可评价数及原因；避免先按干预结果重新界定成模成功。
  • ABR阈值和GPIAS主频点需要预先定义；不要根据哪一个频率最显著来倒推“耳鸣频率”。

八、博士课题衔接建议

对于低强度聚焦超声（LIFU）作用于中枢听觉通路的研究，推荐水杨酸钠模型用于急性方法建立和时间窗验证；噪声模型用于持续性耳鸣样行为与干预疗效评估。两者不应默认合并作为同质样本。若超声后GPIAS改善，须同步报告ABR、PPI及原始ASR，以排查因听阈、运动反应或门控机制变化产生的假性“治疗有效”。
